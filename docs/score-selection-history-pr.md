feat: 총보 선택과 그룹 음높이 편집, 악보 전용 Undo/Redo 구현

# PR 본문

악기별로 분리되어 있던 악보를 같은 마디·박자에 정렬한 기본 총보로 표시하고, 사용자 피드백의 1~3단계를 적용합니다. Shift+클릭과 Shift+좌우는 시간·성부 범위를, Ctrl/Cmd+클릭은 다른 악기까지 개별 화음 구성음을 선택합니다. 선택은 음악 ID와 정확한 분수 시점으로 관리해 줄바꿈 뒤에도 유지합니다.

위아래 방향키는 단일·그룹 모두 반음 이동합니다. 그룹은 음정을 보존하며 이동하고 길이 늘리기·줄이기를 모두 거부합니다. 단일 음표의 기존 펜·마우스 길이/음높이 드래그는 유지하며, 제스처 취소는 전체 상태를 복원합니다. 선택한 마디와 음표만 보라색으로 표시하고 기본 텍스트 드래그와 드래그 선택 상자를 차단합니다.

Ctrl/Cmd+Z, Ctrl+Y, Ctrl/Cmd+Shift+Z로 악보 변경을 되돌립니다. 믹서·마스터·프리셋은 현재 값을 유지하며 음원 설정만 변경해도 Redo를 지우지 않습니다.

검증: 타입 검사·린트·프로덕션 빌드·CI 계약 28개, 단위 테스트 209개, Chromium UI 47개, SoundFont 통합 4개 통과. 기존 검증을 삭제하거나 생략하지 않았습니다. 실제 태블릿/S Pen·사람의 음색 평가는 수행하지 않았고, 기존 번들 크기 경고는 남아 있습니다. Actions 결과는 이 브랜치의 Validate 실행 목록에서 확인할 수 있습니다.

이번 범위는 1~3단계입니다. 다중 성부 Ctrl/Cmd+C/V(4단계), 우클릭 도구(5단계), 추가 UI·음색 개선(6단계)은 후속 작업입니다. 기존 단일 마디 메뉴 복사·붙여넣기는 유지합니다. 전문 출판용 자동 레이아웃과 MuseScore WASM 통합은 포함하지 않습니다. main 병합이나 Pages 배포를 실행하지 않습니다.

상세 동작·제한·수동 검토 순서: [선택·히스토리 구현 보고서](https://github.com/ju87-super/PocketScore/blob/feat/score-selection-history/docs/score-selection-history.md).
