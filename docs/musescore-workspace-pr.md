# PR 본문

긴 악보 아래쪽에서 입력할 때 상단 도구가 사라져 문서 처음으로 돌아가야 했다. MuseScore Studio v4.7.5의 편집 창 구조를 참고해 도구/도크/악보/상태 영역을 분리하고, 악보 영역만 스크롤하도록 바꾼다.

입력·재생 도구, 독립 스크롤과 닫기/폭 조절을 지원하는 300px 기본 도크, 접을 수 있는 상단, 상태 막대의 보기/배율, 화면 안에 들어오는 메뉴·알림을 제공한다. 패널이나 화면 폭·배율이 바뀌어도 보이던 마디/오선과 화면 내 위치를 보존한다. 작은 화면의 기보는 흰 종이 안에서 가로 이동한다. 스크롤 시 확정 전 펜 입력은 취소한다. 음악 데이터·기존 키보드/그룹 규칙·파일·오디오는 유지한다.

검증: 신규 Chromium 시나리오 9개(긴 악보 입력/Undo·도크/확대/회전 위치 보존·패널 스크롤·390/800/1280/가로 화면·터치 탐색·펜 취소)를 기존 테스트에 더했다. 타입 검사·린트·224 단위·74 Chromium·4 실제 오디오 통합·28 CI/WASM 도구 계약·프로덕션 빌드를 로컬에서 모두 통과했다. 닫힌 패널의 스크롤 보존을 위해 DOM을 유지하며, 기존 화음 검사는 DOM 부재 대신 화면상 닫힘을 확인한다. 음악 데이터 기대와 기존 테스트는 유지했다. Actions 결과와 [상세 보고서](docs/musescore-workspace.md)를 참조한다.

실제 Galaxy Tab/S Pen과 MuseScore GUI 검증은 수행하지 않았다. 전체 MuseScore 복제, 도크 자유 배치와 미구현 기보 기능까지 완료했다고 주장하지 않는다. 기존 공유 청크 크기 경고는 유지한다.
