# PR 본문

Studio는 8분·16분음표를 묶지 않고, 모든 마디를 가장 복잡한 마디에 맞춘 같은 폭으로 1~2개씩 배치했다. 이제 박자와 분수 시점에 맞는 빔을 그리고, 음표·화음·임시표의 실제 폭을 측정해 시스템마다 들어갈 마디 수와 폭을 결정한다.

2/4·3/4의 박별 빔, 4/4의 8분음표 반 마디 묶기와 16분음표 세부 분리, /8 박자의 세 음 묶기, 쉼표에서 끊기를 지원한다. 다중 성부의 기둥 방향을 유지하고 큰 도약에서 빔의 과도한 기울기를 제한한다. 같은 박자는 모든 오선에서 정렬하며, 단독 온마디쉼표의 표시 길이와 실제 길이를 분리한다. 화면/패널/배율 변경에서도 기준 마디의 세로 위치를 보존한다.

새 단위 17개와 실제 Chromium 11개를 추가했다. Music Engine CI에 조판 단위를 포함하고 기존 음악 데이터·선택·입력·단축키·Undo/Redo·파일·오디오 검사를 유지한다. 로컬 타입·린트·단위 241·Chromium 85·오디오 4·도구 계약 28·프로덕션 빌드가 모두 통과했다. 상세 범위·캡처와 최종 결과는 [보고서](docs/basic-engraving.md) 및 Actions를 참조한다.

수동/오선 간 빔, 붙임줄·연음표와 인쇄 조판은 후속 범위다. 실제 Galaxy Tab/S Pen·MuseScore GUI 검증은 수행하지 않았다. 기존 청크 경고는 유지한다.
