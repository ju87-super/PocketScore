# 2단계 — 성부 복사·붙여넣기와 문맥 도구

2026-10-27 사용자가 승인한 다음 단계다. 최신 main `843263ee877ce5363e62db62f50371dd3d05a61c`, AGENTS.md와 PR 상태를 확인하고 `feat/score-clipboard-context`에서 구현했다. 이전 조판 개선과 기존 입력·선택·히스토리를 유지한다. PR 생성은 사용자가 수행한다.

## 화면 조작

- 상단 **선택 복사 / 선택 위치에 붙여넣기** 버튼, **편집 → 선택 요소 복사 / 붙여넣기**, **Ctrl/Cmd+C·V**가 같은 음악 명령을 사용한다.
- 음표·쉼표·마디를 우클릭하면 문맥 메뉴를 연다. 이미 선택한 구성음 안에서 우클릭하면 그룹을 유지하고, 그룹 밖에서는 클릭한 대상을 선택한다. 붙여넣기 기준은 우클릭한 음표/쉼표의 시작 또는 마디 시작이다.
- 상단 **선택 작업** 버튼으로도 같은 메뉴를 연다. 마우스 우클릭을 사용할 수 없는 펜·손가락에서도 화면 버튼으로 접근한다.
- 메뉴에는 복사·붙여넣기, 선택 음 삭제, 반음 위/아래, 길이·임시표, 화음 전체 선택, 끝에 마디 추가와 속성 열기를 제공한다. 그룹의 길이·임시표 변경과 쉼표의 음높이·임시표 변경은 비활성화한다.
- 메뉴는 화면 안으로 배치하고 낮은 가로 화면에서는 내부 스크롤한다. 실제 외부 스크롤·화면 크기 변경·창 이탈·바깥 클릭·Escape에서 닫는다. 열기 직전의 자동 스크롤에서 늦게 도착한 같은 위치의 알림은 메뉴를 닫지 않는다.
- 메뉴의 기본 방향키 탐색과 Home/End, 닫은 뒤 악보 포커스를 지원한다. 제목·입력칸·선택 상자·편집 가능한 텍스트·도움말에서는 기존 텍스트 복사/붙여넣기와 편집을 유지한다.
- 기존 **마디 복사 / 마디 붙여넣기** 메뉴도 유지하며, 이 경로는 대상 마디 시작의 첫 성부부터 붙여넣는다.

MuseScore Studio v4.7.5의 [NotationView.qml](https://github.com/musescore/MuseScore/blob/v4.7.5/src/notationscene/qml/MuseScore/NotationScene/NotationView.qml)의 요소별 `onShowContextMenuRequested`와 메뉴 표시/닫기 구조를 확인했다. 실제 데이터와 명령은 PocketScore의 기존 선택 규칙에 맞춰 별도 TypeScript/React 코드로 구현했다. MuseScore의 Qt 메뉴나 네이티브 클립보드 형식과 호환된다는 의미가 아니다.

## 음악 데이터 계약

### 복사

`src/project/clipboard.ts`는 SVG/DOM/오디오 없이 동작한다. 복사본에는 성부별 상대 시작 시점, 길이, 선택한 실제 음높이만 넣는다. 원본 ID·SVG 좌표·악기 설정·믹서는 넣지 않으며 분수와 음높이 값은 원본에서 분리한다.

- 단일 화음 구성음은 그 음만 복사한다. Shift 범위는 기존 규칙대로 화음 전체와 사이 성부의 선택된 요소를 포함한다.
- Ctrl 목록은 직접 고른 구성음과 성부만 복사한다. 클릭 순서에 관계없이 선택된 성부를 위에서 아래로 정렬하고, 고르지 않은 중간 성부는 압축해 제외한다.
- 선택한 음표 사이의 상대 시간 간격은 유지한다. 범위 안의 빠진 박은 붙여넣을 때 쉼표로 채운다.
- 일반 선택의 시간 범위는 가장 이른 선택 시점부터 가장 늦은 선택 요소의 끝까지다. 마디 선택은 선택한 마디 전체 시간을 포함한다. 여러 행은 같은 시간 범위를 공유한다.
- 복사는 음악 데이터·Undo/Redo에 들어가지 않는다. 이후 원본을 수정하거나 다른 프로젝트를 열고 Undo/Redo해도 복사해 둔 음은 유지된다.

### 붙여넣기

- 시작 위치는 선택한 음표/쉼표의 시작 박이다. 마디를 선택했으면 마디 시작을 사용한다.
- 복사한 첫 성부를 대상 성부에 놓고, 이후 행은 기존 성부→다음 오선→다음 악기의 화면 순서로 배치한다. 성부·오선·악기를 자동 생성하지 않는다. 악보 아래에 행이 부족하면 남은 복사 행을 건너뛰고 상태에 개수를 표시한다.
- 복사 범위의 기존 내용을 덮어쓰며 범위 밖의 시점·음표는 유지한다. Ctrl 목록의 빠진 박과 행별 앞뒤 빈 시간도 복사 범위 안에서는 쉼표로 덮어쓴다.
- 뒤 마디가 부족하면 모든 오선에 필요한 마디만 추가하고, 다른 행의 늘어난 시간은 쉼표로 채운다.
- 원본과 대상의 조표·음자리표가 달라도 실제 음높이와 표기를 보존한다. 필요한 임시표는 기존 계산기가 표시한다. 대상 악기·믹서·템포는 유지한다.
- 박자가 달라도 음표가 대상 마디 안에 들어가면 상대 시점·길이를 그대로 옮긴다. 쉼표는 마디선에서 나눌 수 있다. 음표가 마디선을 넘거나 기존 음표의 경계 조각에 붙임줄이 필요하면 이유를 알리고 전체 작업을 거부한다.
- 드럼의 지원 음, 128마디, 16,000이벤트, 성부 합계·ID 불변식 등을 검증한 후에만 전체 결과를 확정한다. 행 일부를 계산한 뒤 오류가 나도 음악·추가 마디·히스토리·Redo는 변경되지 않는다.
- 붙여넣은 음표·쉼표에는 새로운 ID를 주고 결과를 그룹으로 선택한다. 여러 성부와 추가 마디를 한 번의 Undo/Redo로 복원한다. 현재 믹서·마스터·음색 설정은 되돌리지 않는다.

클립보드는 `ProjectState`의 일시 상태이며 프로젝트 JSON 스키마와 음악 스냅샷에는 들어가지 않는다. 이 구현은 앱 내부 클립보드다. 새로고침/탭 종료 뒤 유지, 다른 탭·외부 앱·MuseScore 클립보드와의 교환은 지원하지 않는다. 잘라내기와 붙임줄·연음표 확장은 후속 범위다.

## 검증

새 단위 **21개**는 구성음 부분 복사, Shift/Ctrl 행과 시간 범위, 반대 방향 선택, 쉼표, 분수/점 길이, 덮어쓰기 경계, 다른 조표·박자, 행 부족, 전체 마디 추가, 중간 오류의 원자성, 새 ID, 파일 재로드·재생, Redo 보존과 믹서 격리를 확인한다. 읽는 프로젝트와 클립보드를 동결한 검사도 포함한다.

새 실제 Chromium **14개**는 다음을 검증한다.

1. 여러 성부/오선 Shift 범위의 Ctrl+C/V 덮어쓰기와 두 Redo 단축키.
2. Ctrl로 고른 화음 구성음과 비연속 성부의 상대 시점·쉼표.
3. 화면 버튼과 우클릭으로 복사·붙여넣기, 모든 오선의 뒤 마디 추가와 한 번의 Undo.
4. 그룹 안 우클릭 선택 보존, 그룹 밖 단일 선택, 부족한 행 건너뛰기.
5. 메뉴의 그룹 반음 이동·길이 차단·화음 전체 선택·단일 길이 편집·쉼표 임시표 차단.
6. 복사가 Redo를 유지하고 이후 원본 변경과 분리되는지 확인.
7. 텍스트 입력칸의 기본 Ctrl+C/V와 음악 데이터 보존.
8. 마디선을 넘는 붙여넣기 거부와 추가 마디/히스토리 보존.
9. Meta+C/V.
10. Chromium 펜 우클릭 에뮬레이션과 음표 입력/드래그 방지.
11. 390×844 메뉴 경계·포커스·Escape·화면 버튼·바깥 클릭.
12. 800×1280에서 같은 검사.
13. 1280×900에서 같은 검사.
