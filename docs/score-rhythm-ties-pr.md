# PR 본문

짧은 리듬과 붙임줄이 없어 동일 음의 지속을 여러 번 발음해야 했다. 이제 32·64분음표/쉼표와 점32분·점16분을 편집하고, 기존 인접 음표의 화음 구성음을 같은 성부 안에서 연결·해제할 수 있다. 마디/시스템 경계 곡선, 임시표, 논리 음의 일괄 음높이 변경, 내부 연결의 복사·붙여넣기와 Undo/Redo를 함께 처리한다.

재생은 연결 구간을 하나의 MIDI 발음으로 합친다. 실제 PCM 검사에서 발견한 긴 지속음의 seek/resume 무음도 수정해 해당 시점의 활성 선율 키를 복원한다. MusicXML의 32nd/64th·tie/tied와 기존 v2 JSON을 지원하며, 잘못된 연결은 거부한다. 음악 모델에는 SVG 객체를 저장하지 않는다.

새 단위 41개와 Chromium 13개·실제 PCM 1개를 추가했다. 기존 262 단위·99 Chromium·4 PCM 시나리오를 유지한다. 고정 MusicXML과 실제 exporter 출력은 공식 4.0 XSD를 통과했다. 전체 검증 수치와 제한은 [상세 보고서](score-rhythm-ties.md)를 참조한다.

로컬 타입·린트·actionlint·프로덕션 빌드·303 단위·35 도구 계약·Chromium 111개 전체와 추가 재로드 1개·실제 오디오 5개가 통과했다. 최종 브랜치 Actions에서는 Chromium 112개 전체를 실행한다.

자동 마디 분할/다중 조각 입력, 점64분·점온음표, 연음표·교차 성부/오선·타악기 붙임줄은 후속이다. 그룹 길이 변경 금지와 현재 믹서를 유지하는 악보 Undo/Redo는 그대로다. 실제 태블릿·MuseScore GUI·Pages 배포 검증은 수행하지 않았다.
