# PR 본문

여러 성부를 그룹으로 선택해도 기존에는 한 오선의 마디 전체만 복사할 수 있었다. 이제 선택한 음표·쉼표·화음 구성음의 상대 분수 시점을 복사하고, 대상부터 기존 아래 성부/오선/악기 순서로 덮어쓴다. 부족한 행은 건너뛰고 필요한 뒤 마디는 모든 오선에 추가하며, 전체 작업은 한 번의 Undo로 복원한다.

Ctrl/Cmd+C·V, 상단 버튼과 편집 메뉴가 같은 독립 음악 명령을 사용한다. 우클릭 및 선택 작업 버튼에는 복사·붙여넣기·삭제·반음·길이·임시표·화음 선택·속성을 제공한다. 선택된 그룹 안의 우클릭은 그룹을 유지하고, 작은 화면에서 메뉴 경계·포커스·닫기를 처리한다. 그룹 길이/임시표와 쉼표 음높이/임시표는 차단하고 텍스트 입력칸의 기본 클립보드는 유지한다.

새 단위 21개와 실제 Chromium 14개를 추가했다. 기존 음악·조판·선택·입력·파일·오디오 검사를 유지했다. 로컬 타입·린트·262 단위·99 Chromium·4 실제 오디오 통합·28 도구 계약·프로덕션 빌드를 모두 통과했다. Chromium/오디오의 실패·생략·불안정 재시도는 0개다. [상세 보고서](docs/score-clipboard-context.md)를 참조한다.

앱 내부 클립보드이며 탭 재시작/외부 앱 교환은 지원하지 않는다. 붙임줄이 필요한 입력·경계 조각과 지원하지 않는 드럼 음은 전체 작업을 거부한다. 실제 Galaxy Tab/S Pen 테스트는 수행하지 않았으며 기존 청크 경고는 유지한다.
