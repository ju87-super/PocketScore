# PR 제목

feat: split melodic input and paste across barlines with automatic ties

# PR 설명

마디선을 넘는 음표 입력과 붙여넣기를 거부하던 제한을 해제합니다. 입력·붙여넣기가 같은 분수 기반 구간 편집기를 사용하며, 마디 경계와 여러 표기 조각을 붙임줄로 연결하고 부족한 마디를 전체 총보에 추가합니다. 예를 들어 4/4 마지막 박에 입력한 2분음표는 마디를 걸치는 두 4분음표로 표시되며 한 지속음으로 재생됩니다.

새 분할 입력의 화음 구성음도 전체 길이에 연결합니다. 덮어쓰기 구간 밖의 기존 음과 앞뒤 붙임줄, 복사한 부분 화음 연결을 보존합니다. 커서는 전체 길이 뒤로 이동하고 한 번의 Undo/Redo가 마디 추가까지 복구합니다. 그룹 길이 제한, 성부 아래 매핑/초과 행 건너뛰기, 현재 믹서 설정 보존은 유지합니다.

기존 화면 크기 변경 검사는 렌더링 완료를 기다리고 시스템과 시작 기호를 같은 DOM 스냅샷에서 비교하도록 수정합니다.

실제 PCM 검사에서 드러난 슬라이더 위치 되돌림도 수정합니다. AudioWorklet의 위치 이동 확인 전에는 이전 엔진 시계로 최신 요청을 덮지 않습니다.

타입·린트·빌드, 단위 328개, Chromium 전체 119개와 추가 화면 화음 1개, 실제 PCM 6개, CI/WASM 계약 35개 및 실제 출력의 MusicXML 4.0 XSD 검증을 통과했습니다. GitHub의 최종 커밋 결과와 자세한 범위는 [변경 보고서](automatic-tie-input.md)에서 확인할 수 있습니다. 타악기 붙임줄·연음표·기존 연결 이벤트의 길이 변경은 이번 범위에서 제외합니다. 실제 태블릿 또는 MuseScore GUI 테스트를 수행한 것으로 보고하지 않습니다.
