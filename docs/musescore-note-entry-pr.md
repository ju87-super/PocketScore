# PR 제목

feat: MuseScore식 음표·화음 입력과 입력 커서 구현

# PR 본문

기존에는 속성 패널에서 3도씩 추가해야 화음을 만들 수 있었습니다. 이제 빈 악보에서 `N → 5 → C → Shift+E → Shift+G`로 4분 도미솔 화음을 직접 입력하고 다음 위치에서 입력을 이어갑니다. 입력 모드에서 같은 박자의 다른 높이를 마우스·펜으로 눌러도 화음이 됩니다.

MuseScore v4.7.5의 키 정의를 참고해 3~7 길이, 점음표, A–G, Shift 화음, 0 쉼표, 성부 전환, Esc, 삭제, Space 재생·일시정지를 연결합니다. 입력 위치는 분수로 관리하며 새 음표는 대상 성부의 시간 범위만 대체합니다. 지원하지 않는 붙임줄·마디선 초과는 전체 거부하고, 악보 끝의 새 마디와 입력은 한 번의 Undo로 취소합니다.

사용자 지시에 따라 Studio 좌우 드래그 길이 변경을 해제하고 숫자키·도구로 통일합니다. 상하 음높이 드래그, 기존 Shift/Ctrl 선택, 그룹 길이 변경 금지, 반음 이동, 음원 설정을 유지하는 Undo/Redo는 보존합니다. Legacy 입력과 양방향 드래그 회귀 테스트도 유지합니다.

검증 범위: 단위 223개(신규 14개), Chromium UI 57개(신규 실제 입력 10개), SoundFont 통합 4개, CI 계약 28개, 타입 검사·린트·프로덕션 빌드. 실제 통과 여부는 이 브랜치의 Validate 결과와 artifact에서 확인합니다. 실제 Galaxy Tab/S Pen·MuseScore GUI·사람의 음색 평가는 수행하지 않습니다.

32분·64분·겹온음표, 일부 점음표, 자동 붙임줄·연음표, MIDI와 나머지 MuseScore 입력 모드는 미지원입니다. 기존 번들 크기 경고는 남아 있습니다. 다중 성부 복사·붙여넣기와 우클릭 도구는 후속 단계입니다. main 병합이나 Pages 배포를 실행하지 않습니다.
